MULTI-GUARD DECISION LAYER

정확도는 하나의 모델보다
여러 번의 판단에서 나옵니다.

STOOM의 핵심은 번역 모델을 무겁게 만드는 것이 아니라, 음성인식 이후의 작은 판단들을 촘촘하게 연결하는 것입니다. 각 판정기는 혼자 정답을 결정하지 않고 서로 다른 증거를 제공하며, 충분히 안전할 때만 다음 단계에 영향을 줍니다.

LAYER 01
◉

무슨 소리를 들을지

Main Speaker Guard, 환경 판정, TTS Output Guard가 메인 화자와 배경 소리를 구분하고 잘못된 입력 시작을 줄입니다.

LAYER 02
⌁

어디까지가 한 문장인지

Acoustic Endpoint, Fast Endpoint, Continuous Soft Boundary가 침묵과 종결 표현을 함께 보며 문장 경계를 결정합니다.

LAYER 03
◇

무슨 말을 했는지

N-best, 음운·음향 혼동, 문맥, Topic Pack, Personal Acoustic Vector가 가까운 후보를 다시 비교합니다.

LAYER 04
✓

바꿔도 안전한지

형태론·contrast·margin·ownership·adaptive learning gate가 과교정과 잘못된 자기학습을 제한합니다.

WHY STOOM

실시간 강의에서 실제로 필요한 판단들.

정확한 번역만큼 중요한 것이 빠른 확정, 전문용어 보존, 화자 구분, 중복 방지입니다. STOOM은 강의실에서 자주 생기는 실패 지점을 독립적인 안전계층으로 다룹니다.

MAIN SPEAKER

배경 소리보다 강사를 우선

발화 에너지와 개인/세션 화자 프로필을 함께 보며 메인 화자의 시작·지속·종료를 추적합니다.

배경 발화가 endpoint를 흔드는 문제를 줄이는 역할
PERSONAL ACOUSTIC VECTOR

개인의 발음 습관을 후보 판단에 활용

초성·모음·종성의 changed-span을 비교해 특정 단어 암기가 아니라 반복되는 음향 혼동 패턴을 후보 점수에 반영합니다.

Calibration Core + Adaptive Runtime + Session Evidence
N-BEST + CONTEXT

Chrome 1순위를 무조건 믿지 않음

가까운 N-best 후보를 문맥·발음·개인벡터·용어 근거로 다시 평가하고 충분한 margin이 있을 때만 제한적으로 역전합니다.

후보 생성보다 후보 선택을 더 똑똑하게
TOPIC PACK

전문용어를 보호한 채 번역

강의 주제별 용어와 사용자 지정어를 인식·번역 과정에서 보호하고 목표 언어의 권장 표현으로 복원합니다.

표기 차이 정규화 + 안전 토큰 복원
TTS OUTPUT GUARD

번역 음성이 다시 번역되는 것을 억제

음성통역 재생 시작·종료와 echo tail을 추적해 출력 음성이 새로운 입력으로 오인되는 상황을 줄입니다.

실제 강사가 계속 말할 수 있도록 완전 mute 대신 조건 강화
LATE FINAL OWNERSHIP

늦게 온 Final도 원래 문장으로

recognition generation·result index·segment·텍스트 관계를 확인해 늦은 Final을 직전 카드에 귀속하고 중복 번역을 억제합니다.

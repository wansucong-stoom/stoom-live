권장: 최신 Chrome 데스크톱 · 안정적인 인터넷 연결 · 강의 시작 전 10초 마이크 테스트. 번역은 지원되는 Chrome의 Translator API를 사용합니다. 2개 언어를 선택하면 두 언어 모델을 각각 준비하며, 첫 사용 시 언어팩을 내려받을 수 있습니다.

강의 용어집 관리

원문 언어와 번역 언어를 지정해 반드시 사용할 번역어를 등록합니다. 한국어→영어뿐 아니라 영어·일본어·중국어→한국어 방향도 등록할 수 있습니다.

0개 등록
적용 방식: 현재 강의 언어와 일치하는 등록 용어를 보호 토큰으로 바꾼 뒤 Chrome Translator API에 전달하고, 번역 결과에서 해당 번역 방향의 지정 번역어로 복원합니다. 예: “핵심역량 → core competency”와 “core competency → 핵심역량”을 각각 등록할 수 있습니다.

용어 인식 강화

Chrome STT가 반복해서 잘 못 듣는 단어만 등록하세요. 한국어와 English 강의에서 사용하며, 각 용어를 기본 5회 읽고, 패턴이 부족하면 2회 더 측정해 실제 오인식 패턴만 개인 프로필에 저장합니다.

0개 등록
음성 원본은 저장하지 않습니다.
권장 대상: 신조어, 사람 이름, 브랜드명, 약어, 학과·기관·연구과제명처럼 Chrome이 반복적으로 잘 못 듣는 단어입니다.
5회 중 4회 이상 정확하면 “인식 양호”로 저장합니다. 동일 오인식이 반복되면 자동보정 근거로 사용하고, 패턴이 부족하면 2회 추가 측정할 수 있습니다.

발음 등록

평소 강의할 때처럼 먼저 5회 읽습니다. 반복 패턴이 부족한 경우에만 2회 추가 측정해 최대 7회까지 확인합니다.
